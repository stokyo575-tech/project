🚀 PUSH KE GITHUB - STEP BY STEP
================================

✅ SEMUA PATH SUDAH DI-UPDATE!

Berikut step untuk push ke GitHub:

---

## STEP 1: Setup Git Credentials

```bash
# Set nama & email
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```

---

## STEP 2: Initialize Git Repository

```bash
cd c:\Users\ASUS\Downloads\RianModss-main
git init
```

---

## STEP 3: Add All Files

```bash
git add .
```

---

## STEP 4: First Commit

```bash
git commit -m "Initial commit: WhiteGpt with Qwen AI thinking display"
```

---

## STEP 5: Add Remote Repository

**OPTION A: Jika belum ada repository:**
1. Buka https://github.com/new
2. Buat repository baru dengan nama: `RianModss` atau `whitegpt-qwen`
3. **JANGAN** initialize dengan README (kosongkan semua pilihan)
4. Copy URL repository (HTTPS atau SSH)
5. Jalankan:
```bash
git remote add origin https://github.com/YOUR-USERNAME/REPO-NAME.git
```

**OPTION B: Jika sudah ada repository:**
```bash
git remote add origin https://github.com/YOUR-USERNAME/REPO-NAME.git
```

---

## STEP 6: Push ke GitHub

```bash
# Push ke main branch
git branch -M main
git push -u origin main

# Atau push ke master branch
git push -u origin master
```

---

## STEP 7: Enable GitHub Pages

1. Buka repository di GitHub
2. Klik **Settings** (di menu atas)
3. Scroll ke bawah, cari **Pages** (di sidebar kiri)
4. Di **Source**, pilih:
   - Branch: `main` (atau `master`)
   - Folder: `/ (root)`
5. Klik **Save**
6. GitHub akan build & deploy otomatis

---

## STEP 8: Akses Website

Tunggu 2-3 menit, kemudian buka:
```
https://YOUR-USERNAME.github.io/RianModss/
```

Atau sesuai URL di GitHub Pages settings

## 🐛 JIKA ADA ERROR

### Error: "fatal: refusing to merge unrelated histories"
```bash
git pull origin main --allow-unrelated-histories
git push -u origin main
```

### Error: "fatal: 'origin' does not appear to be a 'git' repository"
```bash
# Check remote
git remote -v

# Remove & add again
git remote remove origin
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```

### Error: Authentication failed
- Gunakan GitHub token (Settings > Developer Settings > Personal Access Tokens)
- Atau setup SSH key
