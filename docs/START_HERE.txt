STEP 1: Test Frontend (2 menit)
  □ Open index.html di browser
  □ Ctrl+Shift+R (clear cache)
  □ Sidebar seharusnya muncul di kiri
  □ Test "New Chat" button

STEP 2: Setup Backend (5 menit)
  □ mkdir backend && cd backend
  □ npm init -y
  □ npm install express cors dotenv
  □ cp ../SERVER_TEMPLATE.js server.js
  □ echo "PORT=3000" > .env
  □ node server.js

STEP 3: Test API (3 menit)
  □ curl http://localhost:3000/api/health
  □ Send message di frontend
  □ Check ./logs/{username}/savechat.log

STEP 4: Deploy (5 menit)
  □ Frontend: vercel deploy
  □ Backend: Render/Railway
  □ Update API URL
  □ Test production
